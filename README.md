# CV wall

1. Create a GitHub repo, upload `index.html` and the `cvs/` folder.
2. Settings → Pages → Deploy from branch `main` / root.
3. Each person uploads their CV as `cvs/1.pdf` … `cvs/5.pdf`
   (GitHub web: open `cvs/` → Add file → Upload files).
4. Edit names / roles / info / links in the `PEOPLE` block at the top of the script in `index.html`.
   A `pdf` can also point to a raw GitHub link from someone's own repo.
5. Open the site, hit **QR**, show it. On a person's page the QR links straight to their CV.
